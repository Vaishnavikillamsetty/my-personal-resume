# 📄 Resume Showcase Website

A simple, responsive **resume/portfolio website** built to showcase personal details, skills, projects, and contact information in a clean and professional format.  
Ideal for students and beginners who want an online presence and a shareable resume link.

---

## 🚀 Features

- Clean and minimal resume layout  
- Responsive design (desktop & mobile friendly)
- Sections for profile, skills, education, and projects
- Easy to customize HTML and CSS
- Can be hosted using GitHub Pages

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage  
- **CSS3** – Styling and layout  
- **JavaScript** – Basic interactivity (if used)

---

## 🧑‍💻 How to Run the Project Locally

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/resume-showcase-main.git
   ```

2. Open the folder
   ```bash
   cd resume-showcase-main
   ```

3. Open `index.html` in your browser
   - Double-click it  
   OR  
   - Use Live Server in VS Code

That’s it. If a project needs more steps, it should justify them—this one doesn’t.

## ✏️ Customization

Edit `index.html` to update:
- Name
- Education
- Skills
- Projects

Modify `style.css` to change:
- Colors
- Fonts
- Layout

No backend. No database. Simple by design.
